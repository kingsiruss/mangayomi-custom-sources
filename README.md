# Custom Mangayomi Sources

Private repository with custom extensions for **Luscious** (manga) and **Eporner** (anime/video).

## How to add in Mangayomi

1. Go to **More → Settings → Browse**
2. Add these repos:

**Manga extensions repo:**
```
https://raw.githubusercontent.com/kingsiruss/mangayomi-custom-sources/main/index.json
```

**Anime extensions repo:**
```
https://raw.githubusercontent.com/kingsiruss/mangayomi-custom-sources/main/anime_index.json
```

> **Note:** Private repos may not work with raw.githubusercontent.com links without authentication. If Mangayomi cannot load them, temporarily make the repository public (Settings → Danger Zone → Change visibility) or switch to a public gist.
